# sfacg_downloader

一个从 [SF轻小说](https://book.sfacg.com/) 下载轻小说的小工具，支持免费章节和已订阅的付费章节，可导出为 `TXT` 或 `EPUB`。

小说 ID 就是小说详情页地址中的那串数字。

![示例](p1.png)

## 功能

- 使用手机号 + 密码登录，登录后的 cookie 会自动保存到 `config.conf`，下次运行自动复用/续期
- 也支持在 `config.conf` 中预先填写账号密码，实现全自动登录，无需交互输入
- 并发下载章节（线程数可在 `config.conf` 中调整），并对失败请求自动重试
- 本地按小说 ID 缓存已下载的免费章节内容（`cache/` 目录），重复下载同一本书不会重复请求
- 已订阅的付费章节可正常下载；未订阅的付费章节会在正文中保留占位提示
- 内置形近字替换词典，修正部分章节正文中被替换/混淆的汉字
- 可按卷选择下载范围（如 `1,3-5`），支持只下载部分卷
- 导出 `TXT` 和带封面的 `EPUB`

## 安装

```bash
pip install -r requirements.txt
```

## 使用

```bash
python main.py
```

首次运行会在当前目录生成 `config.conf`（若不存在），按需填写账号密码后重新运行即可自动登录；也可以留空，按提示手动输入手机号和密码。

`config.conf` 主要配置项：

| 配置项 | 说明 |
| --- | --- |
| `DEVICE_TOKEN` | 设备令牌，建议替换成自己的 |
| `CACHE_DIR` | 章节缓存目录 |
| `DEFAULT_MAX_THREADS` | 默认并发线程数（越大越快，但注意触发反爬） |
| `DEFAULT_MAX_RETRIES` | 每个章节最大重试次数 |
| `user` / `pass` | 账号密码（可选，填写后自动登录） |
| `cookie` | 登录后的 Cookie（优先级高于账号密码，程序会自动写入/更新） |

## 维护工具

`dictionaryMake.py` 是一个可选的维护脚本，用于对比网页版与 App 接口返回的正文，重新生成形近字替换词典（`dict.json`）。日常下载不需要运行它，仅在词典需要更新时使用。
